# Antiviral Quasi-Cells: In Silico Model (HCV Case Study)

Computational study of liposomal decoy particles ("quasi-cells") designed to
capture virions in the bloodstream and eliminate viral genomes before infection.

## Key elements
- Receptor-anchored capture: membrane-integrated ligand (HCV E2 dimer, model 1NFN)
- Multivalent capture regime at 0.2 mol% ligand density
- Intracellular genome degradation without transcription: endonuclease +
  5'-phosphatase + exonuclease cocktail, ~1 min per genome
- Innate-immune (PRR) load reduced ~100-fold by complete degradation to monomers
- Combined administration: 30-min infusion (loading) + SC depot (maintenance)
- Modular design: anchor varies per target (HCV E2, SARS-CoV-2 RBD, influenza HA, HSV gD)
